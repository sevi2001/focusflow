# 🌸 FocusFlow — Your Cozy Productivity Companion

A beautiful, interactive productivity web application designed to make studying, staying focused, and achieving daily goals more enjoyable.

FocusFlow combines productivity tools, adorable virtual pets, a rewarding study experience, and a personal postcard collection in one cozy digital space. 💜

## 🌐 Live Demo

🚀 **Live Website:** https://focusflow-delta-liard.vercel.app/

💻 **GitHub Repository:** https://github.com/sevi2001/focusflow

## ✨ Features

### 📊 Personalized Dashboard
- A welcoming productivity dashboard.
- Quick access to different application features.
- A visually appealing interface with smooth animations.

### 📚 Interactive Study Room
- A dedicated environment for focused study sessions.
- A cozy and distraction-free study experience.
- Interactive elements that make studying more engaging.

### 🏆 Rewards System
- A fun rewards section to encourage productivity.
- Gamified elements that make progress feel rewarding.
- Motivational features to support consistent study habits.

### 🐾 Virtual Pets
- Adorable virtual companions.
- A playful experience integrated into the productivity application.

- Choose from 20 beautiful pastel paper colors.

- Password-protected access to personal postcards.

- Private notes stored in the browser.

### 🎀 Animated User Interface
- Pastel-inspired designs and cozy visual elements.
- Smooth transitions and interactive animations.
- Responsive layouts for different screen sizes.
- Cute icons, decorative elements, and personalized styling.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sevi2001/focusflow.git
```

### 2. Navigate to the Project

```bash
cd focusflow
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

http://localhost:5173

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 🔒 Privacy & Data Storage

FocusFlow uses browser-based Local Storage to save application data.

Private postcards are protected through client-side encryption and a password-protected vault.

**Important notes:**
- Data saved in Local Storage belongs to the browser and device where it was created.
- Private postcards do not automatically synchronize across devices.
- Clearing browser storage may permanently delete saved data.
- The application does not currently provide cloud-based account synchronization.
